# Architecture decision records

Short, permanent records of settled decisions: what was decided, why, and what
was rejected. A decision that changes what core does is also reflected in
[`docs/specs/core-app.md`](../specs/core-app.md).

Files are named `NNNN-short-slug.md`, numbered in order. A decision is never
edited after it is accepted; a later ADR supersedes it and says so.
