## What Sovereign is

Sovereign is open-source, self-hostable software. The project publishes the
source code, this documentation, a plugin registry, and official mobile/
desktop shell apps that make it easier to reach a self-hosted instance. The
project does not operate any instance, does not provide the service you use
day-to-day, and is not responsible for how any operator runs their
instance.
