# RFCs

Proposals that need a detailed plan — design, motivation, alternatives and
tradeoffs — reviewed as a document before implementation. How to propose one is
in [CONTRIBUTING.md](../../CONTRIBUTING.md#proposing-a-feature-rfcs).

Files are named `NNNN-short-slug.md`, numbered in order; withdrawn numbers are
not reused. Each RFC carries a `Status:` line, kept in step with the table below.

| RFC                              | Title                     | Status                                                      |
| -------------------------------- | ------------------------- | ----------------------------------------------------------- |
| [0001](0001-installable-core.md) | An installable core (PWA) | Accepted; partially implemented (the manifest and metadata) |
